# Offline dictionaries — the licensing record (Campaign 4 Phase 3)

A downloadable dictionary is a data entry in `ml_runtime`'s `ModelRegistry`
(`packages/ml_runtime/lib/src/registry.dart`, `ModelRegistry.starter()`),
the same registry law every model file already follows: `url + sha256 +
bytes`, fully pinned, fail-closed on unpinned. This file is the verbatim
licensing record, so the choice can be checked rather than trusted — the
same shape `docs/reference/tts-voices.md` already established.

## Starter dictionary: `wiktionary-en-en-stardict`

**Chosen.** An English-to-English Wiktionary dictionary in real StarDict
format, generated by `Vuizur/Wiktionary-Dictionaries`
(`https://github.com/Vuizur/Wiktionary-Dictionaries`) from
`kaikki.org`/Wiktextract's parse of the English Wiktionary.

- Registry id: `wiktionary-en-en-stardict`
- Source repo: `https://github.com/Vuizur/Wiktionary-Dictionaries`
- Direct file: `https://raw.githubusercontent.com/Vuizur/Wiktionary-Dictionaries/master/English-English%20Wiktionary%20dictionary%20stardict.tar.gz`
- Fetched and hashed locally: 2026-08-15
- Size: 21,839,699 bytes (~20.8 MiB)
- sha256: `2800f630d2975ea29a7b5763e7d79ed71dab9abcc6157534d75c7cd721e8b64b`
- Contents (verified by extracting locally, not assumed from the
  filename): a real StarDict set —
  `English-English Wiktionary dictionary.ifo` (`version=3.0.0`,
  `wordcount=462079`, `synwordcount=394031`, `sametypesequence=h` — entries
  are HTML-formatted), `.idx` (standard binary word\0+offset+length
  format, verified byte-for-byte against the StarDict spec), `.dict.dz`
  (dictzip — verified the gzip FEXTRA field carries the `RA` dictzip
  subfield identifier at the expected offset, confirming this is a real
  random-access dictzip and not a plain gzip mislabeled), and a `.syn`
  synonym-index file (not consumed by this pass's parser).
