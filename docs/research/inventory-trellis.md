# trellis inventory

Trellis (/mnt/tera/working/programming/OpenHearth/Trellis, Flutter ~2900 lib LOC, v1.0.0+3) is the sole reader of the .ohcourse line (ADR-0008; ohPrimer retired, its reading engine dropped not ported). Loop: import/bundle a .ohcourse -> course map with mastery + prereq locks -> study session (RSVP intake, then recall items) -> self/auto grade -> SM-2 reschedules -> mastery unlocks downstream concepts. Local-first: no network calls at all; storage is entirely SharedPreferences behind CardRepository ('cards:<courseId>' JSON blob of itemId->{ease,intervalDays,dueEpochDay,reps,lapses}) and CourseRepository ('imported_ids' + 'course:<id>' raw JSON; bundled via assets/courses/index.json).

Rebuild-critical semantics: (1) SM-2 in whole UTC epoch days: q(again/hard/good/easy)=2/3/4/5; EF'=EF+(0.1-(5-q)(0.08+(5-q)*0.02)), clamped >=1.3; q<3 = lapse (interval 0, due today, reps 0, lapses++, relearned same session via end-of-queue requeue with cleared inputs); success: base = firstIntervalDays(reps0) | 6(reps1) | round(interval*newEase), hard x0.6 / easy x1.3, then the monotonic floor newInterval=max(that, oldInterval+1) — a successful recall must never shorten OR plateau the interval (repeated Hard once decayed 7,6,5,4,3,2... un-mastering and re-locking nodes; the +1 avoids the plateau). (2) Mastery: item mastered iff interval>=7 days; node mastery = fraction mastered; node unlocked iff every prereq at mastery 1.0 — but the lock applies only to first exposure (a started node never re-locks in the queue). (3) Grading: cloze/discrimination auto (normalized exact match / index); qa/procedure keyword-coverage suggestion (<=0 again, <0.5 hard, <0.85 good, else easy; no-anchor: empty->again else good) with honest self-rating driving the SRS. (4) Parser: schemaVersion '1.0' only; strict on required fields per type, tolerant on optionals; rejects unknown/self/cyclic prereqs with path-qualified errors; never half-imports.

Also shipped: ORP-pivot RSVP reader (dwell-weighted, 150-800 WPM), genanki-faithful native-only .apkg export (subdeck per node, stable sha1 guids), encrypted .ohbk sanctuary backup (bundled-course progress included, content only for imported; destructive index-last restore; startup vault snapshot), no-remote-fetch markdown/LaTeX rendering, bundled 26-concept Kalman course. 132 test cases encode the invariants — the monotonic-interval property and unlocked-never-relocks property tests are the crown jewels to port verbatim.

## Jank
- **Cold start loads megabytes; every graded answer rewrites a whole blob** — root cause: SharedPreferences is the entire store (ADR-0002): getInstance() loads every value (incl. ~460KB course bodies) into heap before runApp; each grade saves the full cards:<courseId> map via setString, which on Android rewrites the whole backing file; whole-map read/write not designed for thousand-card decks. — fix: VISION 'Near' horizon: move course bodies to files (native) with a web-PWA answer for localStorage sync/quota limits, keep index + small cards: values in prefs; or ship the Drift store the repository seams were shaped for. Must also update TrellisBackupSerializer's read surface.
- **Empty-app problem: 'Nothing due right now' for 144 of the first 200 days; one new concept per week, 98 days to reach the last of 26** — root cause: Unlock bar == mastery bar: a concept unlocks only when EVERY item of EVERY prereq reaches the 7-day interval, and the bundled course is near-linear (2 root nodes). Progression is gated on the calendar, not effort — documented as a pedagogy decision, not a bug (the 'recalled once' alternative opens all 26 on day 0). — fix: Explore between the poles per VISION: a lower unlocking threshold than displayed mastery, or a deliberate 'study ahead' affordance so a due-empty day still offers work.
- **No intake: app cannot take in a source (EPUB/URL/podcast/transcript); language-learner-via-podcast use case unserved** — root cause: ADR-0008 retired ohPrimer and its reading engine (podcast/RSS subscription + auto-download, Whisper transcription with per-word timing, NLLB 22-language translation, Kokoro/SpeechT5 read-aloud, EPUB/URL intake, multi-profile libraries, per-block extracts) was dropped, not ported — in Flutter it is a rebuild. — fix: Nearest step per VISION: in-app intake (transcript/EPUB/URL -> course), currently done externally by the trellis-author skill; on-device speech is the far end.
- **diagramMermaid is parsed and spec'd but never rendered anywhere in the UI** — root cause: Field flows through models/parser (models.dart:116) but no presentation widget consumes it (grep confirms zero UI references). — fix: Render node diagrams on the intake/map surface, or drop the field from the spec claim.
- **Import is paste-JSON-only; no file picker for .ohcourse files** — root cause: LibraryScreen._import is a paste dialog (library_screen.dart:48); large course files are awkward to paste on mobile. — fix: Add file_picker / share-target import alongside paste.
- **No review history or analytics; over-rating learners get unearned schedules; restore not crash-atomic; Anki export hidden on web** — root cause: Only current SM-2 state per item is stored (no revlog); qa/procedure grading is honest self-rating with keyword suggestion only (no judge model); shared_preferences lacks cross-key transactions (mitigated by index-last write order + vault snapshot); export needs dart:io + sqlite3. — fix: Documented trade-offs in docs/limitations.md — a rebuild should preserve them knowingly: add a revlog if moving to Drift/FSRS; keep index-last restore ordering; keep web/native export facade.
